### 🌟 Featured Project — [SkillUpAcademy](https://skillupacademyhub.netlify.app)

An **ed-tech platform** I designed and built solo — from UI to backend to AI integration — to help engineering students study smarter.

| Feature | What it does |
|---|---|
| 🧠 **AI Exam Panic Remover** | Groq-powered AI tool that generates instant revision cheat sheets & key concepts on demand |
| 📚 **Learning Zone & Notes** | Structured, branch-wise notes, tutorials and PYQs |
| 📝 **Quiz Engine** | Interactive quizzes for self-assessment |
| 👨‍🏫 **Mentor Connect** | Lets students reach out to mentors directly from the platform |
| 🔐 **Secure Auth** | Google OAuth 2.0 + SHA-based encryption for user data |

**Tech stack:** HTML, CSS, JavaScript, Node.js, Groq API, Supabase, Google OAuth 2.0

🔗 **Live:** [skillupacademyhub.netlify.app](https://skillupacademyhub.netlify.app)
